02 · small surface area

Команды без шума

Одна команда — одна идея. Можно читать реализацию и сразу проверять её поведение в лаборатории выше.

KV

SET / GET

Положи значение в RAM и получи его по ключу. Отсутствующий ключ возвращает NULL.

∑

FIND / COUNTS

Найди все ключи со значением или посчитай, сколько раз оно встречается.

↶

ROLLBACK

Верни активный слой к snapshot-состоянию, не затрагивая родительскую транзакцию.

↗

COMMIT

Подтверди слой или передай его исходные значения на уровень выше.

03 · under the hood

Снимок при первом изменении

Когда транзакция меняет ключ впервые, GhostDB сохраняет его прежнее значение в текущем слое. Дальше ROLLBACK восстанавливает снимок, а COMMIT переносит историю во внешний слой.

01
BEGINДобавляет новый пустой слой.
02
SET / UNSETСохраняет старое значение ключа один раз.
03
COMMIT / ROLLBACKПрименяет изменения или собирает состояние назад.
01transactions = []
02BEGIN → T1
03SET A 10
04BEGIN → T2
05SET A 20 # snapshot A=10
06ROLLBACK # A ← 10
07COMMIT # T1 applied
08// nothing persisted to disk
